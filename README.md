# Book Gallery — плагин Obsidian

Каталог прочитанных книг: бенто-карточки, таблица, фильтры (автор, жанр, оценка, теги, поиск), статистика месяца, три карточки инсайтов («Инсайт месяца», «Инсайт года», «Случайный инсайт»), «Пульс прочитанных за год», тексты из заметок-цитат. Инсайты месяца и года выбирают лучшие по оценке книги с доступным текстом; случайный инсайт выбирается из остальных книг каталога. Работает без Dataview и без сборки — это обычные JavaScript-файлы.

## Установка («скопировал — вставил»)

1. Скопируйте папку `book-gallery` целиком в `<хранилище>/.obsidian/plugins/`.
2. В Obsidian: **Настройки → Сторонние плагины** → отключите «Безопасный режим» → включите **Book Gallery**.

`main.js` в этой папке уже содержит все модули и стили, поэтому плагин работает, даже если установщик скопировал только `main.js` и `manifest.json`. Папки `src/` и `styles/` нужны только для правки кода.

### Правка кода и пересборка

Исходники — `main.source.js` (загрузчик), `src/*.js` и `styles/*.css`. После правок выполните `node build.js` (из папки плагина): он пересоберёт `main.js` со встроенными модулями. `node build.js <папка>` собирает пару `main.js` + `manifest.json` в указанную папку.

## Использование

В заметке достаточно вставить пустой блок:

````markdown
```book-gallery
```
````

Параметры блока необязательны и переопределяют настройки плагина, кроме папки с книгами: она всегда берётся из **Настройки → Book Gallery → Папка с книгами**. Старый параметр `folder` внутри блока игнорируется, поэтому даже блок с `folder: Book Notes` не сможет добавить заметки из этой папки в каталог. Все параметры — в **Настройки → Book Gallery** (имена свойств вводятся с автокомплитом); в блоке можно переопределить `filterField`, `filterValue`, `title`, `dateFormat`, `dateLocale`, `openInNewTab`, `defaultView` (`cards`/`list`), `defaultSort`, `tagMode`, `bigShare`, `bigMinChars`, `showStats`, `showPulse`, `fullWidth` и др.

Имена свойств задаются вложенным ключом:

````markdown
```book-gallery
fields:
  title: Title
  author: Author
```
````

Кроме блока доступны: вкладка **«Каталог книг»** (значок на боковой панели или команда), команды «Вставить блок каталога», «Обновить каталоги».

## Формат заметки о книге

```yaml
---
Название: Солярис
Автор: Станислав Лем
Жанр: Фантастика
Оценка: 9
Дата прочтения: 2026-09-07
cover: "[[solaris.jpg]]"
tags: [sci-fi, философия]
Цитата: Короткая ключевая мысль
Страниц: 240
---
```

Свойство `Прочитано` необязательно и не участвует в поиске книг: заметки попадут в каталог независимо от наличия и значения этого поля.

Заметка-цитата связывается с книгой свойством `Источник` (`Источник: "[[Солярис]]"` или просто название). Книги для каталога берутся только из папки «Папка с книгами»; заметки-цитаты — из «Папки заметок-цитат». Если папка заметок-цитат не задана, поиск ограничен папкой книг, а не всем хранилищем:

```markdown
---
Источник: "[[Солярис]]"
---
Note
Текст цитаты

Комментарий
```

Тексты в карточках берутся по приоритету: случайная заметка-цитата → свойство `Цитата` → отрывок из самой заметки книги. Большую карточку получают только книги, у которых достаточно текста.

## План на год и инфокарточки

В настройках плагина («План на год») или в блоке можно задать цель:

````markdown
```book-gallery
yearGoal: 52          # книг за год
yearGoalPages: 15000  # страниц за год (необязательно)
yearGoals:            # свой план для отдельных лет (необязательно)
  2025: 40
```
````

Под «Пульсом года» показываются инфокарточки за выбранный в «Пульсе» год: план (кольцо, «опережаете/отстаёте на N», сколько нужно в месяц), темп и прогноз к концу года, серия месяцев подряд, страницы (с прогрессом к цели), распределение оценок по целым звёздам, чаще читаемые жанр и автор, а также пять самых популярных тегов. Клик по оценке, жанру, автору или тегу включает соответствующий фильтр. Дополнительно показываются отдельные карточки жанров, авторов и тегов за весь период — без ограничения по году. При заданном плане в «Пульсе» появляется пунктир: сколько книг в месяц нужно для цели. Отключить карточки: `showProgress: false`.

## «Книга года»

Лучшая по оценке книга из показанных (с достаточным текстом и оценкой не ниже `featuredMinScore`, по умолчанию 4.5 из 5). При равной оценке выигрывает книга с большим числом заметок, затем самая свежая. Идёт первой, широкой карточкой.

## Раскладка и фильтр оценки

- **Колонки зависят от ширины:** примерно одна на каждые ~300 px, от 2 до 8 (на телефоне 2, на большом мониторе 6–8), карточки не растягиваются.
- **Staggered grid:** CSS-сетка с колонками равной ширины и карточками разной высоты (по пропорциям обложки и объёму текста); порядок сортировки читается слева направо, пустот нет. «Книга года» — широкая карточка сверху на две колонки. Среди остальных изредка (≈12 %, параметр `wideShare`, `0` — отключить) встречаются широкие карточки «обложка слева, текст справа» на две колонки; если рядом с широкой карточкой остаётся пустота, она сама становится обычной одноколоночной. «Большие» карточки показывают цитату целиком с комментарием.
- **Фильтр по оценке** показывает целые звёзды. Для шкалы 5 баллов сохраняются диапазоны: 5★ = 5.0; 4★ = 4.0–4.5; 3★ = 3.0–3.5; 2★ = 2.0–2.5; «Менее 2». Для шкал выше 5 оценка переводится в пятизвёздочную и округляется к ближайшей целой звезде: на шкале 10 баллов 5★ = 9–10; 4★ = 7–8; 3★ = 5–6; 2★ = 3–4; «Менее 2» = 0–2.

## Обложки

Свойство `cover` (имя настраивается) понимает: `[[файл.jpg]]`, `![[файл.jpg]]`, `[[папка/файл.jpg|300]]`, `![](файл.jpg)`, путь `папка/файл.jpg` (в том числе URL-кодированный) и ссылку `https://…`. Имя свойства ищется без учёта регистра (`Cover` = `cover`). Если файл по ссылке не найден точно, плагин ищет файл с таким именем по всему хранилищу. Если какие-то обложки не нашлись, внизу каталога появится «обложек не найдено: N» (при наведении — примеры), а подробности — в консоли разработчика.

Если файла из `cover` нет (например, картинку переименовали, а текст в свойстве остался прежним) или свойства нет вовсе, берётся первая картинка, встроенная в текст заметки (`![[файл.webp]]`). Отключается параметром `coverFromBody: false`.

В карточках обложка заполняет всю область и обрезается по краям (`coverFit: cover`, по умолчанию); `coverFit: contain` показывает обложку целиком. Обложки уменьшаются до 560 px; если уменьшение не удалось или заняло дольше 6 секунд, показывается оригинал.

## Автообновление

Каталог тихо обновляется через пару секунд после правки заметок книг и цитат; фильтры и выбранный вид сохраняются.

## Структура

| Файл | Назначение |
|---|---|
| `build.js` | сборка: `main.source.js` + `src/` + `styles/` → `main.js` |
| `main.js` | готовая сборка: загрузчик + все модули и стили внутри |
| `main.source.js` | исходный загрузчик (блок кода, вкладка, команды, автообновление) |
| `src/config.js` | параметры по умолчанию и слияние |
| `src/data.js` | чтение книг из `metadataCache` |
| `src/notes.js` | заметки-цитаты, отрывки |
| `src/stats.js`, `filters.js` | статистика, фильтрация (без DOM) |
| `src/cards.js`, `list.js`, `templates.js`, `icons.js`, `thumbs.js` | отрисовка |
| `src/ui.js`, `app.js`, `layout.js` | интерфейс, сборка, ширина заметки |
| `src/settings.js`, `view.js` | настройки, вкладка |
| `styles/*.css` | стили (тёмная и светлая темы) |

Модули читаются через `app.vault.adapter` и исполняются как функции, поэтому плагин работает и на мобильных устройствах.

## Оценка, время чтения, новые книги

- **Оценка на карточке:** параметр `scoreFormat` — `native` (по умолчанию, «7/10» по шкале `ratingMax`) или `stars` («3.5» по пятизвёздочной шкале). Фильтр по звёздам и средние оценки в статистике следуют тому же формату.
- **Время чтения** (свойство `Время чтения`, необязательное) — формат `ЧЧ:мм` (`16:40`; понимаются также `3 ч 20 м`, `90 мин`, число = часы). Показывается на карточках и в списке, суммируется в карточке месяца и «Пульсе года», есть карточка «Время чтения» (итог, в день, на книгу, самая долгая) и сортировка по времени.
- **Размер книг:** короткие (до 3 ч), средние (3–8 ч), долгие (8–15 ч), толстые (от 15 ч). Если времени нет, оценивается по страницам (`minutesPerPage`, по умолчанию 2 мин на страницу).
- **«Добавить книгу»** создаёт заметку только с основными свойствами из настроек: название, автор, жанр, теги, дата прочтения и оценка. Остальные свойства можно добавить вручную, когда они понадобятся.
- Карточки не растягиваются больше чем на 90 px: если рядом с широкой карточкой остаётся большая пустота, она становится обычной.
- **Телефон:** в мобильном приложении Obsidian (телефон) карточки идут в один столбец и одного размера: обложка слева, текст справа. На планшете и десктопе раскладка прежняя.
